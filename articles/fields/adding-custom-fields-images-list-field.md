## Propósito

El campo Lista de imágenes proporciona una lista desplegable de archivos de imagen para seleccionar para su visualización en la salida del artículo en una lista separada por espacios.

## Creación del campo

Las opciones especiales de este campo son:

- **Directorio** La ruta del sistema de archivos al directorio que contiene los archivos de imagen que se mostrarán en la lista. Solo se pueden seleccionar imágenes de un único directorio.
- **Múltiple** Permite seleccionar varios valores.
- **Clase de imagen** La clase que se añadirá a la imagen. Por ejemplo, *w-25 p-1* limita el ancho de cada imagen al 25 % de su contenedor y añade 1 unidad de relleno.

![creación del campo de lista de imágenes](../../../en/images/fields/adding-custom-fields-images-list-field/01-fields-images-list-edit.png)

**Nota:** En este ejemplo, la inclusión del tipo de campo en el título tiene únicamente fines demostrativos. Omítalo en los títulos de sus propios campos.

## Entrada de datos

Sencillo: seleccione una o más imágenes de la lista.

![entrada de datos del campo de lista de imágenes](../../../en/images/fields/adding-custom-fields-images-list-field/02-fields-images-list-data-entry.png)
