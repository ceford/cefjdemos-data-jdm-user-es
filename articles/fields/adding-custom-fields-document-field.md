## Propósito

El campo de documento permite seleccionar un archivo de documento de una carpeta de archivos.

## Creación del campo

Los parámetros comunes de los campos se describen en un artículo independiente.

* **Título** El título se ve y se utiliza en la lista de campos.
* **Etiqueta** Esto es lo que se muestra en la salida. Si se deja vacío, se establece
a partir del contenido del campo Título, pero se puede cambiar.

![creación del campo de documento](../../../en/images/fields/adding-custom-fields-document-field/01-fields-document-edit.png)

**Nota:** En este ejemplo, la inclusión del tipo de campo en el Título es solo para
fines ilustrativos. Omítalo en los títulos de sus propios campos.

## Introducción de datos

El campo de documento es sencillo de usar. Seleccione el archivo de documento requerido mediante un
selector de medios.

![introducción de datos del campo de documento](../../../en/images/fields/adding-custom-fields-document-field/02-fields-document-data-entry.png)
